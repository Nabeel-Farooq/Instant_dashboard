BillBoard

A customizable subscription tracking dashboard built for people who want a clean way to manage recurring payments, monitor spending, and visualize subscriptions in one place.

BillBoard lets you create fully personalized dashboards with draggable widgets, detailed subscription management, and automatic persistence using local storage — no accounts or setup required.

✨ Features
🧩 Drag & resize widgets on a responsive 12-column grid
🗂 Multiple savable dashboards
📊 Interactive analytics widgets & charts
💳 Full subscription management system
📅 Track upcoming billing dates
🧠 Automatic localStorage persistence
🚀 No login or backend required
🎨 Clean customizable dashboard UI

🚀 Getting Started
1. Clone the repository
git clone https://github.com/your-username/billboard.git
2. Navigate into the project
cd billboard
3. Install dependencies
npm install
4. Start the development server
npm run dev
